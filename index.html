Standardalgorithmus: Durch ein Array durchzählen

Um jedes Element eines Arrays nacheinander zu verarbeiten (z. B. zur Ausgabe oder Berechnung), nutzt man standardmäßig eine for-Schleife mit .length:

// 1. Klassische Zählschleife (mit Index-Zugriff)
for (int i = 0; i < werte.length; i++) {
    System.out.println("Element an Index " + i + ": " + werte[i]);
}

// 2. Moderne for-each-Schleife (nur zum Lesen)
for (int wert : werte) {
    System.out.println("Wert: " + wert);
}

Index & Zählung

Die Schleife läuft von i = 0 bis i < werte.length, da das letzte Element bei length - 1 liegt.

Länge (.length)

Ermittelt automatisch die Anzahl der Elemente, wodurch der Code flexibel bei unterschiedlich großen Arrays bleibt.
