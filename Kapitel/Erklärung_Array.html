Arrays in Java verstehen

Interaktives Lehrmodul verknüpft mit dem Quellcode der Wetterstation

1. Was ist ein Array? (Quelltext trifft Speicher)

Ein Array ist eine lineare Datenstruktur, die mehrere Elemente desselben Datentyps (z. B. int) in einer festen Reihenfolge speichert. Im Java-Projekt der Wetterstation wird ein Array für die 24 Stunden eines Tages angelegt.

Java-Quelltext (Aus der Main)

// 1. Deklaration & Erzeugung (Größe: 24)
int[] messwerte = new int[24];

// 2. Befüllung per Schleife
for (int i = 0; i < messwerte.length; i++) {
    messwerte[i] = (int)(Math.random() * 8 + 20);
}

// 3. Übergabe an die Wetterstation
Wetterstation w = new Wetterstation(messwerte);

Grafische Entsprechung (Das Regal)

Im Arbeitsspeicher sieht das Array wie eine Aneinanderreihung von nummerierten Fächern aus. Jedes Fach besitzt einen festen Platz – den Index.

Regal-Größe (length): 24 Fächer
Erstes Fach: Index [0]
Letztes Fach: Index [23] (length - 1)
